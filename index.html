Purpose and choices

BBIDS Security provides browser security observations, phishing-risk predictions, unwanted redirect protection and ad-handling features. Cloud phishing analysis is optional and off by default in version 1.2.0. Choose “Enable cloud analysis” in the popup to turn it on; choose “Disable cloud analysis” to stop future analysis requests. Local protection continues without cloud analysis. Disabling or removing the extension stops its operation.

Information handled on your device

BBIDS inspects the current webpage URL, navigation and popup attempts, resource domains, form destinations, and page structure. It uses local observations to show security reports and control navigation. It also detects YouTube ad indicators and attempts to skip or advance detected ads, sometimes temporarily changing playback speed and mute state.

Per-tab URLs, analysis results and behavior events are stored in Chrome session storage. They are generally cleared on tab closure or browser-session end. Local settings and site behavior profiles, including origins and blocked destination information, persist across restarts. The most recent blocked redirect can include full source and destination URLs. Uninstalling the extension removes its extension storage from that browser profile.

Information sent for cloud predictions

When enabled, the extension sends HTTPS POST requests to https://bbids-backend.onrender.com/predict and /predict-stage2. Requests contain the full webpage URL and, for Stage 2, these 17 numerical counts or presence flags:

HasTitle, HasFavicon, IsResponsive, HasDescription, NoOfiFrame, HasExternalFormSubmit, HasSocialNet, HasSubmitButton, HasHiddenFields, HasPasswordField, HasCopyrightInfo, NoOfImage, NoOfCSS, NoOfJS, NoOfSelfRef, NoOfEmptyRef, NoOfExternalRef.

Full URLs may include paths, query parameters, fragments, personal information or tokens. A HasPasswordField flag indicates a field exists; the extractor does not read its typed password value. Full page text, screenshots, cookies and typed form values are not sent as separate prediction fields. The network connection also exposes standard connection metadata, including an IP address, to the hosting infrastructure.

The backend computes URL features and runs trained models, returning risk scores and feature data. These predictions are not guarantees that a website is safe or malicious.

Processing, sharing and retention

Render hosts the prediction backend in Singapore (Southeast Asia). Requests may therefore be processed outside your country. We use only Render's built-in logs, with no external logging service connected.

The reviewed prediction server and URL extractor do not explicitly write submitted URLs or feature values to a database or file. The submitted information is processed in memory to produce predictions. The sampled application access logs show timestamps, internal/proxy addresses, request methods and endpoint paths, status codes, response sizes and browser user-agent details; they do not show prediction request bodies. These samples are not a guarantee that no information can appear in other infrastructure or error logs.

Our Render workspace uses the Hobby plan. Render's documented dashboard log retention is seven days (https://render.com/docs/logging). This describes dashboard log availability, not a guarantee that every record held independently by the hosting provider is deleted after seven days. Provider processing is also governed by Render's privacy policy (https://render.com/privacy).

SHAIK SAJID BASHA is the only member with access to the BBIDS Render workspace. Hosting-provider personnel may process data as necessary to operate the service under their own policies.

BBIDS uses user data only to provide the disclosed security features. We do not sell user data, use it for advertising, or transfer it for unrelated purposes. BBIDS's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Human access to user data is restricted to circumstances permitted by that policy.

This release does not automatically retrain its ML models or upload local behavior profiles for training. Local behavior profiles are distinct from ML retraining. Changes to data collection or use will be explained in an updated policy and, where required, through renewed consent before they take effect.

Security and requests

Prediction traffic uses HTTPS. Turning cloud analysis off cancels pending client requests but cannot recall information already sent. Contact the publisher above for questions or deletion requests; remove the extension to clear its local extension storage.

If you email support, your email address and the information you choose to send are used to respond to your request. Avoid sending passwords or sensitive browsing details. You can request deletion of support correspondence and any identifiable data under our control by contacting faithfulshaik@gmail.com. We will explain what can be deleted and any applicable retention limitations; we cannot promise immediate deletion of provider-controlled logs.

Changes to this policy

We will update this page and its last-updated date when our practices change. Review this policy before enabling cloud analysis and after material updates.
